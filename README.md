## 🚀 Projects

> These are projects I'm actively building. Repositories will be linked as they become public.

### 🤖 JARVIS: Personal AI Assistant
A voice-enabled desktop assistant for Windows, written in Python. Uses the Groq API for language understanding, with wake-word activation, intent routing, text-to-speech, a GUI dashboard, and integrations with Telegram, Gmail, and Spotify.
**Stack:** Python · Groq API · tkinter

### 🎮 Project Monarch: Gamified Learning Dashboard
A dashboard that turns my AI/ML learning roadmap into quests, XP, and progress tracking, with a rule that every number shown comes from real data.
**Stack:** Next.js · TypeScript · Supabase

### 🌧️ Hyperlocal Rainfall Risk Analysis (semester project)
A prototype that analyses rainfall patterns for a district in Odisha using CHIRPS satellite data. It builds seasonal baselines and anomaly features, trains a Random Forest risk model, and presents results in a Streamlit dashboard.
**Stack:** Python · Google Earth Engine · scikit-learn · Streamlit
